# Funniest Cat Voicemail Greeting

One line, at most 120 characters: the funniest voicemail greeting a cat could record.

Entry: `Meow. Leave a message after the beep. If this is about the vase, I was never here.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
